Developer documentation · v1

快速开始

用几分钟将你的应用连接到 QxAPI。我们的 API 兼容 OpenAI SDK，因此你可以保留熟悉的调用方式，同时获得统一路由和生产级观测能力。

准备好了吗？

你只需要一个 API Key。请在控制台的「项目设置 → API 密钥」中创建，并妥善保存。

安装 SDK

选择你正在使用的语言，安装官方 SDK。

Python

Terminal
pip install qxapi

JavaScript / TypeScript

Terminal
npm install @qxapi/sdk

认证

所有请求都通过 Bearer Token 认证。将 API Key 放在请求头中。

HTTP
Authorization: Bearer your-api-key

发起第一次请求

下面的示例会通过统一端点调用你配置的模型。

Python
from qxapi import QxAPI

client = QxAPI(api_key="your-api-key")
response = client.chat.completions.create(
    model="your-model",
    messages=[{"role": "user", "content": "Hello, QxAPI"}]
)

API 端点

POST/v1/chat/completions

创建一次聊天补全请求。

参数类型必填说明
modelstring是已接入的模型标识
messagesarray是按顺序排列的消息列表
streamboolean否是否启用流式响应

错误处理

当请求失败时，QxAPI 会返回标准 HTTP 状态码和可读的错误信息。建议对 429 和 5xx 响应使用指数退避重试。
