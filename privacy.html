QxAPI / PRIVACY POLICY

隐私政策

了解使用 QxAPI 时涉及哪些信息、处理目的以及你的相关权利。

01适用范围

本政策说明使用 QxAPI 网站、账户及 API 服务时涉及的信息处理。具体数据范围与实际使用的功能、提交内容和服务配置有关。

当你通过 QxAPI 调用第三方模型时，供应商也可能处理请求数据。相关处理还受该供应商适用的隐私条款和数据安排约束，请在选择模型前了解这些条件。

02涉及的信息与用途

账户与联系信息
在注册、账户管理或联系支持时，你可能提供邮箱、账户标识等信息，用于身份识别、账户维护和回复请求。
API 请求内容
根据调用方式，请求可能包含提示词、对话历史、文件、图片、工具参数及模型输出，用于完成推理、转发和结果返回。请避免提交与任务无关的个人信息。
运行与安全记录
服务运行可能涉及 IP 地址、请求时间、模型标识、请求编号、状态码、耗时与用量等信息，用于故障排查、计费核查和安全防护。
交易与支持资料
使用付费功能或提交支持请求时，可能涉及订单、支付状态、账单及你主动提供的材料，用于订单处理、售后与争议解决。

03处理目的与合法依据

信息处理应限于提供服务、履行订单、保障安全、响应支持请求和履行法定义务等明确目的，并遵循最小必要原则。

根据适用法律，处理依据可能包括履行合同所必需、你的同意或法定义务。对于需要单独同意或额外告知的处理，应在相应业务流程中完成；不能将本页面的展示视为你已作出同意。

04模型供应商与其他接收方

完成模型请求需要将相关输入传递给实际处理请求的供应商。基础设施、支付或支持服务提供方也可能在必要范围内处理相关信息。

模型供应商是否留存内容、是否将内容用于训练、留存期限及处理地区，取决于具体供应商、账户条款和所选服务配置。本政策不代表所有模型均提供零留存或禁止训练承诺；敏感业务应在接入前确认相应数据安排。

除履行服务所需、取得适用授权或依法履行义务外，其他披露应满足适用法律要求。涉及业务转让等主体变更时，应依法告知相关处理安排。

05保存期限与删除

不同数据的必要保存期限可能不同：账户信息用于账户存续期间的服务管理，运行日志用于有限期间内的排障与安全核查，订单和账单记录可能因法定义务保留更长时间。

具体留存周期应与实际配置及法律要求一致。超出必要期限后，应删除或匿名化；备份中的删除可能随备份轮换完成。对因法律要求暂时不能删除的信息，应限制其处理用途。

如需确认某一项目、模型或日志的保存安排，请通过服务支持渠道提出查询。

06Cookie、本地存储与外部资源

网站可能使用必要的 Cookie 或本地存储维持会话、保存偏好或支持安全功能。你可以通过浏览器设置管理或清除这些数据，但部分功能可能因此受影响。

当前首页和文档页引用 Google Fonts 字体资源。访问这些页面时，浏览器可能向字体服务发送 IP 地址、浏览器信息及加载请求；该服务按其自身政策处理请求信息。字体资源加载失败时，页面使用系统字体回退。

如果后续引入非必要的统计或营销技术，应按适用法律提供相应告知和选择方式。

07信息安全与使用建议

信息安全措施应与数据类型和处理风险相匹配，包括访问控制、传输保护、权限管理及事件处理。任何网络服务都无法保证绝对安全。

  • 将 API Key 保存在服务端，避免在浏览器、公开仓库或截图中暴露。
  • 上传前移除无关的身份、联系方式和保密内容，并取得必要授权。
  • 联系支持时优先提供请求编号和脱敏日志，不要提供账户密码。

发生个人信息安全事件时，应依照法律要求采取措施，并在必要时通知受影响用户及主管机构。

08你的信息权利

在适用法律规定的范围内，你可以请求访问、更正、补充或删除个人信息，撤回基于同意的授权，申请账户注销，以及在适用时请求信息副本、限制处理或提出异议。

可通过 hello@qxapi.com 提交请求，并说明关联账户及希望处理的事项。为防止他人冒用，处理请求前可能需要核验身份，核验资料应限于必要范围。

撤回同意不影响撤回前处理的效力；删除、注销或限制处理可能影响相关功能。存在法定保留义务或其他合法例外时，应说明不能立即满足请求的原因。

09未成年人的信息

未成年人使用服务应遵守所在地法律对年龄与监护人授权的要求。涉及依法需要监护人同意的个人信息处理，应先取得相应授权。

如果监护人发现未成年人未经适当授权提交了个人信息，可以联系服务支持申请核查，并依法进行删除或其他处理。

10跨地区处理

请求处理地区可能随所选模型供应商和基础设施而变化。如果业务对数据存储地或跨境传输有要求，应在发送数据前确认服务配置及供应商处理地区。

涉及依法受限制的跨境处理时，应先满足相应告知、同意及其他法定条件。本页面不对未经确认的部署地点或跨境机制做出保证。

11政策更新与联系

本政策可能因服务或法律要求变化而更新。涉及处理目的、信息类别或接收方等重大变化时，应以适当方式告知，并在法律要求时取得相应授权。

如果对信息处理、供应商数据安排或权利请求有疑问，请联系 hello@qxapi.com。
